# CV LAB 3 – Average Filtering

## Aim

To implement Average Filtering on grayscale images using OpenCV and NumPy.

## Libraries Used

- OpenCV
- NumPy
- Matplotlib
- PIL

## Experiment

In this experiment, Average Filtering is applied to images using different kernel sizes.

### OpenCV Average Filtering

The following filter sizes are applied:

- Average Filter 3 × 3
- Average Filter 5 × 5
- Average Filter 7 × 7

### Manual Average Filtering

The average filter is implemented using NumPy with the following kernel sizes:

- Average Filter 3 × 3
- Average Filter 5 × 5
- Average Filter 7 × 7
- Average Filter 11 × 11
